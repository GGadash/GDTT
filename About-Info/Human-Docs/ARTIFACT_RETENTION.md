## Current release candidate

Published tag `v0.10.1-rc.1` identifies application version 0.10.1. Downloads:

- `GDTT-0.10.1-windows-x64-Portable.zip`: extract, then run `GDTT/GDTT.exe`.
- `GDTT-0.10.1-windows-x64-installer.exe`: current-user installation; no admin required.
- `GDTT-0.10.1-source.zip`: audited source without Git internals, datasets or build output.
- `BUILD_MANIFEST.json`, `LOCAL_C_LITE.json`, `RELEASE_CANDIDATE.md`, `SHA256SUMS.txt`, and
  `VERIFY_CHECKSUMS.ps1`: provenance, acceptance, limitations and verification.

The source is committed to GitHub. These eight downloadable files are published as GitHub
Release assets by the explicit-tag workflow. Local artifacts remain under ignored
`packaging/output/`; do not force-add binaries or operational data to Git.

Local binary renaming preserves content hashes. GitHub builds are independently produced from
the tag and can have different hashes due to build timestamps: always use the checksum file
from the same release download, not the local build's checksum file.
