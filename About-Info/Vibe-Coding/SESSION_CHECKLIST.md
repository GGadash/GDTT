# Session Checklist

- Read repository instructions and current handoff state.
- State scope, requirement IDs, and smallest affected modules.
- Inspect behavior and tests before editing.
- Keep a runnable checkpoint and avoid broad half-refactors.
- Run focused tests, then proportionate regression/lint/type checks.
- Update documentation, registry, changelogs, and current state.
- Review Git status/diff for accidental files and private data.
- Record exact next step; never publish automatically.
